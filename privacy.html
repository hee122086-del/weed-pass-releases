개인정보처리방침

최종 수정일: 2026년 11월 3일

1. 이 방침의 적용 범위

이 방침은 데스크톱 프로그램 위드패스(WeeD-Pass)에 적용됩니다. 위드패스는 학교 상담 담당 교사가 상담 일정과 기록을 관리하기 위해 사용하는 프로그램입니다.

2. 상담 기록의 저장 위치

위드패스에 입력한 학생 정보, 상담 일정, 회기 기록 등 모든 자료는 프로그램을 설치한 컴퓨터 내부에만 저장됩니다. 개발자는 이 자료를 수집하지 않으며, 자료를 보관하는 서버를 운영하지 않습니다. 따라서 개발자는 사용자의 상담 기록을 열람할 수 없습니다.

3. 구글 계정 연동 시 요청하는 권한

구글 캘린더 연동은 선택 기능이며, 사용자가 직접 연결을 요청할 때만 동작합니다. 연동 시 위드패스는 아래 권한을 요청합니다.

  • calendar.app.created — 위드패스가 만든 「위드패스」 캘린더를 생성하고, 그 캘린더의 일정을 조회·생성·변경·삭제합니다.
  • openid, email — 현재 연결된 계정의 주소를 화면에 표시하기 위해 사용합니다.

위드패스는 개인 캘린더 전체에 접근하는 권한을 요청하지 않습니다. 요청하는 범위는 위드패스가 직접 만든 캘린더로 한정되므로, 사용자가 원래 사용하던 개인 캘린더의 일정을 읽거나 수정할 수 없습니다. 위드패스가 다루는 대상은 자신이 만든 「위드패스」 캘린더뿐입니다.

4. 구글로 전송되는 정보

연동을 켠 경우, 일정을 저장할 때 아래 정보가 사용자 본인의 구글 캘린더로 전송됩니다.

  • 일정 제목(상담 유형과 대상자 표시), 날짜, 시작·종료 시간. 대상자·교원 이름은 가운데를 가린 형태(예: 김0희)로 올립니다.
  • 대상자의 학년·반(있는 경우)

상담 회기 기록의 본문, 상담 내용, 첨부 파일, 일정 메모는 전송하지 않습니다. 전송된 정보는 사용자 본인의 구글 계정에만 저장되며, 개발자는 접근할 수 없습니다.

5. 인증 정보의 보관

구글 연동에 사용되는 액세스 토큰과 갱신 토큰은 사용자 컴퓨터에 운영체제의 암호화 기능으로 암호화되어 저장됩니다. 외부로 전송되지 않으며, 다른 사용자나 개발자가 열람할 수 없습니다.

6. 제3자 제공 및 광고

위드패스는 사용자 데이터를 제3자에게 제공하거나 판매하지 않습니다. 광고를 표시하지 않으며, 광고 목적으로 데이터를 사용하지 않습니다. 구글 사용자 데이터를 인공지능 모델의 학습에 사용하지 않습니다.

7. 연동 해제와 데이터 삭제

연동을 끊거나 이미 올라간 자료를 지우려면 아래 방법을 이용하실 수 있습니다.

  • 위드패스의 설정 → Google 캘린더 화면에서 연동 해제를 누르면 컴퓨터에 저장된 인증 정보가 삭제됩니다.
  • 구글 계정의 타사 앱 및 서비스 페이지에서 위드패스의 접근 권한을 언제든지 철회할 수 있습니다.
  • 구글 캘린더에서 「위드패스」 캘린더를 삭제하면 내보낸 일정도 함께 삭제됩니다.
  • 컴퓨터에 저장된 상담 기록은 위드패스의 설정 → 데이터 백업·삭제 화면에서 직접 삭제할 수 있습니다.

8. 구글 API 서비스 사용자 데이터 정책 준수

위드패스가 구글 API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 구글 API 서비스 사용자 데이터 정책을 준수하며, 여기에는 제한적 사용 요건이 포함됩니다.
