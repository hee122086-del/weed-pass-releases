🔒

내 컴퓨터에 저장

모든 기록은 설치한 컴퓨터에만 저장됩니다. 일정 시간 입력이 없으면 화면을 잠그고, 비밀번호로 다시 엽니다.

💾

암호 걸린 백업

컴퓨터 고장이나 오류로 기록을 잃지 않도록 백업 파일을 만들어 둡니다. 백업 파일은 암호로 보호되고, 필요할 때 그대로 복원합니다.

소개 문구

상담 일정·회기 기록·확인증·집단 출석부·상담 대장을 한 번에 관리하는 무료 프로그램 「위드패스」를 소개합니다. 컴시간 시간표를 보면서 상담 시간을 잡고, 학기 말 대장과 나이스 자료도 바로 만들어 줍니다. 상담 기록은 내 컴퓨터에만 저장됩니다. 👉 https://hee122086-del.github.io/weed-pass-releases/

페이지 주소

이 주소 하나만 알려 주면 소개, 다운로드, 사용 설명서를 모두 볼 수 있습니다.

설치나 사용 중 궁금한 점은 hee122086@gmail.com으로 보내 주세요.

자주 묻는 질문

더 궁금한 점은 사용 설명서나 메일로 문의해 주세요.

정말 무료인가요?

네. 학교 상담 업무에 쓰도록 만든 프로그램이며 비용을 받지 않습니다.

상담 기록이 인터넷으로 나가지 않나요?

상담 기록은 설치한 컴퓨터에만 저장됩니다. 인터넷을 쓰는 기능은 컴시간 시간표 조회, 공휴일 불러오기, 업데이트 확인, 그리고 직접 켠 경우의 구글 캘린더 일정 내보내기뿐입니다. 구글 캘린더에는 가린 이름과 날짜·시간만 올라갑니다.

설치할 때 「Windows의 PC 보호」 창이 떠요.

개인이 만든 프로그램이라 처음에 나오는 안내입니다. 추가 정보를 누른 뒤 실행을 누르면 설치됩니다.

컴퓨터가 고장 나면 기록은 어떻게 되나요?

컴퓨터 오류로 기록을 잃지 않도록 설정 → 데이터 백업에서 백업 파일을 저장해 두세요. 문제가 생기면 위드패스를 다시 설치한 뒤 같은 메뉴에서 복원하면 됩니다. 백업 파일을 만들 때 정한 암호가 필요합니다.

컴시간 학교코드는 어디서 알 수 있나요?

컴시간 알리미의 교사용 학교코드이며 나이스 학교코드와 다릅니다. 학교 시간표 담당(일과계) 선생님께 문의해 주세요. 코드가 없어도 교시를 직접 골라 예약과 확인증 출력은 할 수 있습니다.

새 버전은 어떻게 받나요?

위드패스를 켜면 새 버전이 있는지 확인해서 알려 줍니다. 안내에 따라 받으면 기록은 그대로 두고 프로그램만 바뀝니다.
